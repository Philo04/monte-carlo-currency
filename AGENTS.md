# AGENTS.md

## Назначение проекта
Проект представляет собой C++ библиотеку для моделирования курса валют методом Монте-Карло. Реализована симуляция геометрического броуновского движения.

## Структура проекта
- `include/` - заголовочные файлы
- `src/` - исходный код
- `tests/` - unit-тесты (Catch2)
- `benchmarks/` - замеры производительности (Google Benchmark)
- `.github/workflows/` - CI/CD пайплайны

## Команды сборки и запуска
1. **Сборка:** `cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build`
2. **Запуск программы:** `./build/monte_carlo_app`
3. **Запуск тестов:** `ctest --test-dir build --output-on-failure`
4. **Запуск бенчмарков:** `./build/bench_monte_carlo`
5. **Генерация документации:** `cmake --build build --target doc`

## Правила и ограничения для агента
- **ОБЯЗАТЕЛЬНО:** перед завершением любой задачи собрать проект и запустить тесты, чтобы убедиться, что ничего не сломалось.
- **ЗАПРЕЩЕНО:** менять настройки CI/CD (`.github/workflows/ci.yml`) без явного запроса пользователя.
- **Стиль кода:** Придерживаться C++17, использовать `snake_case` для переменных и функций, `PascalCase` для классов. Не использовать исключения (exceptions).
